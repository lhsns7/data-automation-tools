# LLM 서비스 골격

## 이 도구가 하는 일 (비개발자용)
"우리 규정·매뉴얼로 답하는 AI 챗봇"을 서비스로 굴릴 때 필요한 뼈대입니다. 채팅 화면은 오히려 쉬운 부분이고, 실제로 서비스가 망하는 자리는 네 곳입니다 — 요금이 예상 밖으로 나가는 것, 문서에 없는 걸 그럴듯하게 지어내는 것, 남의 대화가 보이는 것, 그리고 "잘 답하나"를 감으로만 아는 것. 이 넷을 구조로 막았습니다.

## 어떤 문제를 풀었나
"우리 문서로 답하는 챗봇"은 데모까지는 하루면 됩니다. 문제는 그 다음입니다. 직원 50명이 쓰기 시작하면 API 요금이 어디까지 갈지 모르고, 문서에 없는 질문에 그럴듯한 오답을 내놓아 신뢰를 잃고, 대화 이력이 섞이고, "요즘 답이 좀 이상한데"를 확인할 방법이 없습니다. 챗봇 프로젝트가 실패하는 지점은 모델이 아니라 운영입니다.

## 결과
- **요금이 예상 밖으로 나가지 않음** — 사용자별 일일 상한·월 요금 상한·사전 견적·캐시로 상한 밖 API 호출이 발생 자체가 0입니다. 관리자 화면에서 사용자별 호출·토큰·요금이 청구서 전에 보입니다.
- **지어내지 않는 답변** — 문서에 근거가 없으면 API를 부르지도 않고 "찾지 못했습니다"로 거절하고, 근거가 있으면 출처 문서·청크를 답변에 붙입니다 — 규정·매뉴얼 챗봇에 맞는 정직선.

## 쓰는 법
```
python llm_app.py --serve  (검증: python llm_app.py)
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.
