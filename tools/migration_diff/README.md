# 데이터 이관 검증기

## 이 도구가 하는 일 (비개발자용)
ERP 교체·DB 이전·엑셀→시스템 적재 같은 데이터 이관 후 "제대로 옮겨졌는가"를 전수 대조로 증명하는 검증 도구입니다. 이관 프로젝트의 최종 관문인 검수를 자동화합니다.

## 어떤 문제를 풀었나
이관 프로젝트의 마지막이자 가장 무서운 질문은 "옮긴 게 맞는가"입니다. 눈검사는 수천 건을 못 덮고, 개발자용 단순 diff를 돌리면 다른 문제가 생깁니다 — 이관하면서 금액에 콤마가 붙고 날짜 형식이 바뀌고 컬럼명이 달라지는 건 정상인데, 이것들이 전부 "차이"로 잡혀 오탐 수천 건에 진짜 훼손이 묻혀버립니다.

## 결과
- **"이관 잘 됐나"를 문장이 아니라 표로** — 구시스템과 신시스템을 키 단위로 전수 대조해 누락·여분·중복·값 훼손을 키와 필드까지 적은 엑셀을 냅니다 — 검수 회의가 짧아집니다.
- **표기 변화는 결함이 아니다** — 컬럼명·금액 콤마·날짜 형식이 달라진 정상 이관본은 차이 0으로 통과합니다 — 가짜 경보로 시간을 태우지 않습니다.

## 쓰는 법
```
python migration_diff.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 클린본(표기만 변화) → 차이 0 = ★오탐 0
- ② 심은 누락 3건 → 키 정확 검출
- ③ 심은 여분 1·중복 2 → 정확 검출
- ④ 심은 필드 훼손 4건(금액+900·날짜 월시프트·잘림·문자훼손) → 키·필드 정확 검출

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
