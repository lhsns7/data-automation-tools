# 라이브 방송·판매 성과 리포트

## 이 도구가 하는 일 (비개발자용)
라이브커머스·홈쇼핑식 방송의 판매 성과를 주문 데이터에서 방송별로 자동 집계하는 리포트 도구입니다. "이 주문이 어느 방송의 성과인가"라는 귀속 문제를 규칙으로 명시하고 자동화합니다.

## 어떤 문제를 풀었나
방송을 여러 회 돌리는 팀의 공통 질문은 "어느 방송이 얼마나 팔았나"입니다. 단순해 보이는데 집계가 매번 흔들립니다 — 방송이 끝난 뒤에도 주문은 계속 들어오고(방송의 잔여 효과), 연달아 이어지는 방송에선 앞 방송의 여운과 다음 방송의 생방이 겹치며, 같은 상품이 두 방송에 다 걸리면 어느 쪽 성과인지 애매해집니다.

## 결과
- **방송 성과를 주문 단위로 귀속** — 주문 시각과 방송 시간표를 맞춰 각 주문이 어느 방송(생방/후속 구매)의 성과인지 자동 판정하고 방송별·상품별로 집계합니다.
- **성과가 두 번 세어지지 않음** — 방송이 연달아 있어도 한 주문은 한 방송에만 귀속되고, 귀속 합계와 제외분을 더하면 전체 매출과 항상 맞습니다.

## 쓰는 법
```
python live_report.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 주문 1건 단위 귀속 전수 일치(32건)
- ② 경계 4케이스(시작·종료·후속끝 정각=포함 / +1분=제외)
- ③ ★겹침(B1 후속 윈도우 ∩ B2 생방) → 방송중 우선
- ④ 총액 보존(귀속 763,000+제외 125,000=888,000) + B2 독립 재집계

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
