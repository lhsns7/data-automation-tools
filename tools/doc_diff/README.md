# 문서 버전 비교 리포트

## 이 도구가 하는 일 (비개발자용)
계약서·규정·약관이 개정될 때 "뭐가 바뀌었나"를 사람이 읽는 색상 리포트로 만들어주는 도구입니다. 개발자용 diff는 비개발자가 못 읽고, 눈 대조는 수치 하나(위약금 3%→5%)를 놓칩니다 — 그 간극을 메웁니다.

## 어떤 문제를 풀었나
개정 검토는 "바뀐 걸 찾는 일"처럼 보이지만, 실제로는 "안 바뀐 걸 확인하는 데" 시간이 더 듭니다. 조항이 자리만 옮겨도 눈에는 변경처럼 보여 없는 변경을 찾느라 헤매고, 정작 수치 하나 바뀐 것(위약금 3%→5%)은 문장 속에 묻혀 눈에 안 보입니다.

## 결과
- **개정 검토를 조항 단위로** — 두 버전을 넣으면 추가·삭제·수정·이동 조항이 색으로 표시된 리포트가 나옵니다 — 비개발자가 브라우저로 바로 읽습니다.
- **돈·기한 변경이 먼저 보임** — 위약금 3%→5%, 통지 7일→14일 같은 수치 변경을 별도 표로 뽑아 계약 검토에서 제일 중요한 것부터 확인합니다.

## 쓰는 법
```
python doc_diff.py 구버전.txt 신버전.txt 리포트.html
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 조항 분류 전수 일치(14항목)
- ② ★이동 2건 오보 0(수정/삭제+추가로 안 잡음)
- ③ 핵심 수치 변경 추출(3%→5% · 7일→14일 · 30일→45일)
- ④ 단어 하이라이트(추가 문구 표시·무변경 단어 미표시)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
