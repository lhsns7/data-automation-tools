# CSV→대시보드

## 이 도구가 하는 일 (비개발자용)
CSV 데이터를 넣으면 KPI·월별 추이·카테고리 차트·검색 테이블이 담긴 대시보드가 HTML 파일 하나로 나오는 도구입니다. 서버도 설치도 필요 없이 더블클릭으로 열리고, 데이터는 파일 안에만 있어 외부로 나가지 않습니다.

## 어떤 문제를 풀었나
데이터를 보는 일은 어느 팀에나 있지만, 그 사이에는 늘 같은 벽이 있습니다. 엑셀로 매번 손으로 집계해 보고서를 만들거나, 제대로 된 BI 도구를 도입하자니 서버 구축·라이선스 비용·사용법 학습이라는 부담이 따라옵니다. 특히 "매주 같은 형식의 데이터를 받아서 같은 형태로 보고하는" 반복 업무라면, 그 중간 어딘가에 훨씬 가벼운 답이 있어야 한다고 생각했습니다.

## 결과
- **보고서 작업 소멸** — CSV를 넣으면 KPI 카드·추이 차트·검색 가능한 표가 있는 대시보드 파일이 바로 나옵니다 — 엑셀로 차트를 만들고 캡처해 붙이는 반복이 없어집니다.
- **설치·서버 없는 공유** — 결과가 HTML 파일 하나라 메일·메신저로 보내면 받는 쪽이 그냥 열어 봅니다. 데이터가 외부 서버로 나가지 않습니다.

## 쓰는 법
```
python csv_dashboard.py 데이터.csv
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (2/4 PASS)
- ① 수치 대조(독립 재집계 vs 집계엔진)
- ② 렌더 스모크(Playwright 실제 열람)
- ③ 경계·격리
- ④ 재현성(2회 동일)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
