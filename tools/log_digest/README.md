# 로그 에러 요약기

## 이 도구가 하는 일 (비개발자용)
서버·앱 로그를 사람이 읽을 수 있는 한 화면으로 요약하는 도구입니다. 수만 줄 로그가 안 읽히는 이유는 양이 아니라 중복 — 같은 에러가 ID·숫자만 바뀌며 수천 번 반복되는 것 — 이라는 관점에서, 가변부를 지운 핑거프린트로 그룹핑하고 운영에서 진짜 중요한 두 신호(처음 보는 에러, 급증한 에러)를 표시합니다.

## 어떤 문제를 풀었나
장애가 나면 로그부터 열지만, 로그는 수만 줄이고 그 대부분은 같은 에러의 반복입니다. "user 12345 not found"와 "user 67890 not found"는 사람 눈에 다른 줄이지만 같은 문제이고, 이런 변형이 수백 개씩 쌓이면 스크롤은 끝나지 않습니다. 정작 위험한 신호 — 어제까지 없던 에러가 배포 직후 처음 나타난 것, 하루 3건이던 에러가 갑자기 60건이 된 것 — 는 그 반복 속에 묻혀 눈으로는 보이지 않습니다.

## 결과
- **수만 줄 로그를 한 화면으로** — ID·숫자만 다른 같은 에러를 한 그룹으로 접어 건수·첫/마지막 발생·예시를 보여줍니다 — 장애 때 로그를 스크롤하지 않습니다.
- **배포 직후 새 에러를 그날 잡음** — 이전 실행과 비교해 처음 보는 에러는 NEW, 갑자기 늘어난 에러는 SPIKE로 표시하고 종료 코드로 알림에 연결됩니다.

## 쓰는 법
```
python log_digest.py 로그파일.log
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 그룹핑 정확(5그룹 · 건수 [3,8,45,120,300] · 총수 보존)
- ② 가변부 일반화(IP 120변형 = 1그룹 · 템플릿에 구체값 0)
- ③ 노이즈 분리(INFO 2,000줄 → 집계 0)
- ④ ★신규 검출(심은 null pointer만 NEW, 기존 5그룹 오탐 0)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
