# 데이터 품질 게이트

## 이 도구가 하는 일 (비개발자용)
데이터를 주고받는 모든 곳(납품·적재·이관·취합)의 관문 도구입니다. "일단 넣고 나중에 발견"이 아니라, 선언한 규칙을 통과해야 지나가는 게이트로 세웁니다. 규칙은 설정 파일이라 코드 수정 없이 대상 데이터만 바꿉니다.

## 어떤 문제를 풀었나
불량 데이터의 비용은 발견이 늦을수록 커집니다. 입력 단계에서 잡으면 그 자리에서 고치면 끝이지만, 적재 후 발견하면 정정과 재작업이고, 고객사에서 발견하면 잃는 건 신뢰입니다. 그런데도 많은 파이프라인이 "일단 넣고 나중에 발견"으로 돌아갑니다 — 검사 코드를 데이터마다 새로 짜는 게 부담이라서입니다.

## 결과
- **불량 데이터가 들어오기 전에 멈춤** — 납품·적재 전에 규칙(타입·필수·범위·형식·허용값·중복·참조·행수)을 통과해야 지나갑니다 — 적재 후 정정하는 비용이 사라집니다.
- **고칠 좌표를 줌** — 위반은 행 번호·컬럼·값·어긴 규칙까지 적어 줍니다. 중복이면 어느 행과 겹치는지, 참조가 끊겼으면 어느 파일에 없는지까지.

## 쓰는 법
```
python data_gate.py 파일.csv
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 심은 위반 8종 전수 검출(행·컬럼·규칙까지)
- ② 위반 수 = 심은 수(초과 검출 0)
- ③ 클린 파일 오탐 0 → 게이트 PASS
- ④ ★참조 무결성(다른 파일에 없는 고객ID) 검출

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
