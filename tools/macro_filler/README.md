# 표(CSV/엑셀)의 각 행을 데스크톱 프로그램에 반복 입력하는 매크로 (2026-08)

## 이 도구가 하는 일 (비개발자용)
여기서는 검증 가능한 대상으로 **메모장**을 씁니다. 실제 주문에서는 이 자리에 고객사 프로그램 창이 들어가고, 창 찾기·입력·저장·확인 절차는 그대로 재사용합니다.

## 쓰는 법
```
python macro_filler.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
