# 업타임·SSL 만료 감시

## 이 도구가 하는 일 (비개발자용)
운영 중인 웹사이트·API가 살아 있는지, SSL 인증서가 언제 만료되는지 감시하는 도구입니다. 사이트 감시의 세 함정 — 죽은 걸 모르는 것, 서버는 200인데 화면은 점검 페이지인 것, 인증서 만료를 까먹는 것 — 을 전부 겨눴습니다.

## 어떤 문제를 풀었나
사이트가 죽으면 고객이 제일 먼저 알고, 운영자는 항의를 받고서야 압니다. 인증서가 만료되면 그 순간부터 전 방문자가 브라우저 보안 경고를 봅니다. 둘 다 "미리 알 수 있었던" 사고인데, 감시를 붙여도 두 가지 함정이 남습니다 — 서버가 200을 돌려주니 정상으로 기록되지만 실제 화면은 점검 페이지인 착시, 그리고 5분마다 같은 경보가 반복돼 결국 알림 자체를 꺼버리는 경보 피로입니다.

## 결과
- **고객보다 먼저 아는 장애** — 사이트가 죽으면 죽을 때 1번, 살아나면 1번만 알립니다. 서버는 200인데 점검 페이지가 떠 있는 착시도 본문 키워드로 잡습니다.
- **인증서 만료 사고 예방** — SSL 만료일을 읽어 D-30 경고, D-7 위험으로 미리 알립니다 — 어느 날 전 방문자가 브라우저 경고를 보는 일이 없습니다.

## 쓰는 법
```
python site_pulse.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (7/7 PASS)
- ① 정상 = UP·응답시간 기록(39ms)
- ② HTTP 500 = DOWN(사유 명시)
- ③ 응답 지연 = DOWN(타임아웃)
- ④ ★200 착시(점검 페이지) = DOWN(키워드 검사)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
