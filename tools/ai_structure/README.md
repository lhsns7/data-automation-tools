# AI 데이터 구조화 템플릿 (2026-09)

## 이 도구가 하는 일 (비개발자용)
고객이 가진 지저분한 데이터(CSV/엑셀) → **분류·정규화·집계·요약** → 바로 쓰는 서식 엑셀. - AI-a(규칙): 무료·결정적·오프라인. `rules.classify()` 하나만 고객 도메인에 맞추면 됨.

## 쓰는 법
```
python ai_structure.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
