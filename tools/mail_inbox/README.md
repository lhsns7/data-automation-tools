# 메일 첨부 자동 수집

## 이 도구가 하는 일 (비개발자용)
거래처·지점이 매일 메일로 보내는 파일(정산서·주문서·재고표)을 사람이 일일이 열어 저장하는 업무를 자동화하는 도구입니다. 규칙(보낸이·제목)에 맞는 메일의 첨부만 골라, 정리된 이름으로, 한 번만 저장합니다.

## 어떤 문제를 풀었나
"메일 확인해서 첨부 저장"은 한 번에 10분짜리 일이지만 매일이고, 사람이 하는 한 빠뜨리는 날이 생기며, 빠뜨린 날의 정산서는 정산을 밀리게 합니다. 자동화하면 되는 일인데 두 가지 함정이 있습니다 — 한글 첨부명은 MIME 인코딩(=?utf-8?B?…?=)이 얽혀 순진하게 저장하면 파일명이 깨지거나 유실되고, 수집기를 재실행하거나 메일이 재수신되면 같은 파일이 두 번 저장되어 후속 취합이 이중 계상됩니다.

## 결과
- **메일 열어 저장하는 10분이 0분** — 거래처·지점이 보내는 정산서·주문서 첨부를 규칙에 맞는 것만 골라 정리된 이름으로 저장합니다 — 빠뜨리는 날이 없어집니다.
- **한글 파일명이 깨지지 않음** — MIME 인코딩된 한글 첨부명을 정확히 복원하고, 같은 메일이 다시 와도 두 번 저장하지 않습니다. 저장 폴더는 그대로 취합 자동화의 입력이 됩니다.

## 쓰는 법
```
python mail_inbox.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 규칙 매칭(수집 2통·첨부 3개 / 규칙 밖 2통 스킵)
- ② 저장 무결(SHA-256 원본=저장, 3/3)
- ③ ★한글 첨부명 정확 복원("9월 정산서_최종.xlsx" 등)
- ④ 중복 재수신 = 저장 0(UID 대장)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
