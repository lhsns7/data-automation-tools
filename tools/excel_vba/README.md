# macros.bas의 VBA 매크로를 LibreOffice(VBA 호환)로 실증.

## 이 도구가 하는 일 (비개발자용)
★반드시 LibreOffice 번들 파이썬으로 실행: "C:\\Program Files\\LibreOffice\\program\\python.exe" verify_lo.py

## 쓰는 법
```
python excel_vba.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
