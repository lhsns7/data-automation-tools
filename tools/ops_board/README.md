# 운영 대시보드 v2

## 이 도구가 하는 일 (비개발자용)
매일 보는 운영 지표판입니다. 흩어진 소스(CSV·데이터베이스·JSON API 산출)를 지표 정의 하나로 통합하고, 실행할 때마다 이력을 쌓아 추이를 보여주며, 임계를 넘은 지표만 경보합니다. 서버·설치 없이 열리는 단일 HTML 파일로 납품합니다.

## 어떤 문제를 풀었나
지표가 CSV 한 장이면 리포트 하나로 충분하지만, 운영이 커지면 소스가 흩어집니다. 판매 데이터는 CSV로, 재고는 데이터베이스에, 시스템 상태는 API 산출로 — 담당자는 매일 여러 화면을 오가며 각각의 숫자를 확인하게 되고, 그러다 보면 정작 중요한 변화를 놓칩니다. "매일 보는 운영 판"은 단발 리포트와 요건이 다르다고 생각했습니다.

## 결과
- **아침에 한 판만 보면 됨** — 매출·재고·서버 오류처럼 흩어진 소스의 지표를 한 화면에 모으고, 임계를 넘은 지표만 빨갛게 표시합니다.
- **어제 숫자를 오늘 것으로 믿는 사고 방지** — 소스가 갱신을 멈추면 "48시간째 새 데이터 없음"을 화면이 스스로 알립니다 — 자동화가 죽은 걸 모르는 가장 흔한 함정을 막습니다.

## 쓰는 법
```
python ops_board.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 지표 독립 재계산 전수 일치(6개, 3형식)
- ② 심은 임계 위반 2건만 경보(정상 4개 오탐 0)
- ③ 이력 축적 3회 실행 = 3점·유실 0
- ④ ★신선도: 48h 묵힌 소스만 스테일 경고

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
