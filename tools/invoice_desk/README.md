# 견적·청구서 발행 + 미수금 추적

## 이 도구가 하는 일 (비개발자용)
프리랜서·소상공인용 청구서 발행과 미수금 추적 도구입니다. 진짜 문제는 청구서를 "만드는 것"이 아니라 "받는 것" — 누가 얼마를 아직 안 냈고 언제부터 밀렸는지 — 이라는 관점에서, 발행과 수금을 한 대장으로 이었습니다.

## 어떤 문제를 풀었나
청구서 자체는 엑셀로도 만듭니다. 문제는 그 다음입니다 — 입금이 청구액보다 적게 들어오고, 완납은 달을 넘겨 나눠 들어오고, 그 사이 새 청구가 쌓이면 "누가 얼마 남았지"가 흐려집니다. 프리랜서·소상공인에게 그 흐림은 곧 못 받는 돈입니다. 밀린 걸 몰라서 독촉을 못 하고, 독촉을 못 해서 더 밀립니다.

## 결과
- **발행부터 완납까지 한 대장** — 청구서를 발행하면 번호·부가세가 자동으로 맞고, 입금이 들어오면 잔액이 갱신됩니다 — 부분 입금이 몇 번 나뉘어도 누가 얼마 남았는지 흐려지지 않습니다.
- **밀린 돈이 먼저 보임** — 지급기한이 지난 청구서는 경과일·잔액과 함께 연체 리포트에 뜨고, 다음 만기는 예정표로 미리 보입니다.

## 쓰는 법
```
python invoice_desk.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (7/7 PASS)
- ① 발행 수기(합계 1,100,000 → 공급가 1,000,000·부가세 100,000 항등)
- ② 채번 20건 — 중복 0·결번 0(2026-0001~0020)
- ③ ★부분 입금 궤적(500,000 부분 → 600,000 완납, 잔액 수기)
- ④ 입금 매칭 분류(정확 4 · 격리 1 — 모르는 입금자)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
