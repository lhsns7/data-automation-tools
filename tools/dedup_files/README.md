# 중복 파일 탐지·안전 정리

## 이 도구가 하는 일 (비개발자용)
공유폴더·다운로드 폴더에 이름만 다르게 쌓인 중복 파일을 내용 기준(해시)으로 찾아 정리하는 도구입니다. 정리 도구의 진짜 문제는 탐지가 아니라 "잘못 지우면 끝"이라는 공포라서, 설계 자체를 "지우지 않는다"로 잡았습니다.

## 어떤 문제를 풀었나
중복 파일 정리는 누구나 필요하지만 아무도 선뜻 못 돌립니다 — 도구가 뭘 지웠는지 모르겠고, 잘못 지운 걸 발견했을 땐 이미 되돌릴 수 없어서요. 그래서 정리 도구의 신뢰는 탐지 정확도가 아니라 "실수해도 돌아올 수 있는가"에서 나온다고 봤습니다.

## 결과
- **잘못 지울 걱정 없는 정리** — 실행하면 정리 계획만 보여주고, 적용해도 지우지 않고 격리 폴더로 옮깁니다. 되돌리기 한 번이면 전부 원위치 — 이 왕복을 검증했습니다.
- **이름 달라도 같은 파일은 잡음** — 내용 해시로 비교해 "보고서(1).md"와 "보고서-복사본.md"를 중복으로 잡고, 1바이트만 달라도 중복으로 오인하지 않습니다.

## 쓰는 법
```
python dedup_files.py 대상폴더 --protect 보호폴더 [--apply | --restore]
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (7/7 PASS)
- ① 탐지 정확(3그룹 구성원 전수) + ★1바이트 차이 오탐 0
- ② 빈 파일 2개 = 중복 처리 안 함(보고만)
- ③ 검수 모드(기본) = 파일시스템 무변화(해시 전수)
- ④ 보존 규칙(보호 폴더 우선 · 최고본 보존)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
