# 파일명 일괄 정리 + 롤백

## 이 도구가 하는 일 (비개발자용)
"IMG_3847.jpg 2천 개" 같은 폴더를 규칙으로 정리하는 일괄 리네임 도구입니다. 일괄 리네임의 공포는 잘못 바꾸면 못 돌린다는 것 — 그래서 이 도구의 본체는 리네임이 아니라 안전장치입니다.

## 어떤 문제를 풀었나
파일명 정리는 누구나 필요하고 누구나 미루는 일입니다. 미루는 이유는 게으름이 아니라 공포입니다 — 일괄 도구가 2천 개 파일을 뭘로 바꿀지 실행 전엔 모르겠고, 바꾸고 나서 이상하면 되돌릴 방법이 없으니까요. 최악은 중간에 이름이 충돌해 반쯤만 바뀐 폴더입니다: 절반은 새 규칙, 절반은 옛 이름, 어느 쪽도 신뢰할 수 없는 상태가 됩니다.

## 결과
- **2천 개 파일명을 겁 없이** — 실행하면 바뀔 이름 계획표만 보여주고, 적용 후에도 --undo 한 번이면 전부 원래 이름으로 — 이 왕복을 검증했습니다.
- **반쯤 바뀐 폴더가 없음** — 두 파일이 같은 이름이 되면 하나만 겹쳐도 적용 전체를 거부합니다. 정리된 폴더에 다시 돌려도 변경 0.

## 쓰는 법
```
python rename_kit.py 대상폴더 [--apply | --undo]
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 변경 계획 = 정답 매핑 전수(5/5)
- ② 검수 모드(기본) = 파일 무변화
- ③ ★충돌 검출(2파일→같은 이름) = 적용 거부·무변화
- ④ 적용: 이름 정확 + 내용 해시 집합 보존

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
