# 측정 데이터 수집·저장 + 무결성 감시

## 이 도구가 하는 일 (비개발자용)
센서·장비·로그처럼 주기적으로 들어오는 측정값을 유실 없이 저장하고, 데이터의 구멍(수신 끊김·범위 밖 값·센서 고착)을 자동 감지해 보고하는 수집·감시 시스템입니다. 측정 데이터를 다루는 설비·IoT·모니터링 용도로 만든 자체 개발 도구입니다.

## 어떤 문제를 풀었나
센서·장비·로그처럼 주기적으로 들어오는 측정값을 다루는 현장의 진짜 문제는 "쌓는 것"이 아니라 "빠짐없이 제대로 쌓였는지"입니다. 수신이 몇 분 끊긴 구간, 범위를 훌쩍 벗어난 값, 센서가 고착돼 같은 값만 반복하는 구간 — 이런 구멍은 수집 시점에는 조용하다가, 몇 주 뒤 분석 단계에서 발견되면 그 기간의 데이터를 통째로 못 쓰게 만듭니다.

## 결과
- **측정값 유실 없는 적재** — 장치가 보낸 값이 그대로 DB에 쌓이고, 재전송이 와도 같은 시각 데이터는 두 번 쌓이지 않습니다 — 나중에 "이 구간 데이터 어디 갔지"가 없습니다.
- **데이터 구멍을 사람이 찾지 않음** — 수집이 끊긴 구간·튀는 값·멈춘 센서를 감시기가 위치와 함께 보고합니다. 원본은 지우지 않고 표시만 붙입니다.

## 쓰는 법
```
python sensor_logger.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 저장 유실 0
- ② 재적재 중복 0 (PK)
- ③ 결측 구간 검출(심은 3)
- ④ 범위 이상값 검출(심은 5)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
