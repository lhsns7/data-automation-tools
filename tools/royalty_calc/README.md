# 콘텐츠·게임 로열티 정산

## 이 도구가 하는 일 (비개발자용)
게임·콘텐츠 판매액에서 저작권자·개발사에게 지급할 로열티를 계약 규칙대로 자동 계산하는 정산 도구입니다. 로열티 정산의 어려움은 곱셈이 아니라 규칙의 모서리 — 구간 요율 경계와 선급금(MG) 이월 — 이라는 문제의식으로 만들었습니다.

## 어떤 문제를 풀었나
로열티 정산은 매달 반복되는데 규칙이 계약마다 다르고, 수작업 엑셀은 늘 같은 곳에서 틀립니다 — 구간 요율의 경계(정확히 상한에 걸린 매출을 어느 구간에 넣나), 그리고 선급금(MG) 차감(이번 달 지급액이 지난달 잔액에 달려 있는 문제)입니다. 특히 MG는 월을 넘어 잔액을 추적해야 해서, 시트가 한 번 어긋나면 그 뒤 모든 달이 연쇄로 틀립니다.

## 결과
- **월 정산을 규칙 하나로** — 판매 내역을 넣으면 채널 수수료·구간 요율·선급금 차감이 계약 설정대로 계산돼 파트너별 명세 엑셀이 나옵니다.
- **틀리면 도구가 먼저 압니다** — 지급+선급금 차감=로열티 항등을 스스로 검산해 1원이라도 어긋나면 해당 파트너를 표시합니다 — 사람이 검산하기 전에.

## 쓰는 법
```
python royalty_calc.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 구간 누진 수기(순 10,400,000 → 3구간 = 1,555,000)
- ② ★구간 경계(순매출 = 정확히 상한 3,500,000 → 상위 구간 0원)
- ③ ★MG 이월 궤적(지급 0→0→부분 · 잔액 550,000→70,000→0 등 2계약)
- ④ 대사 항등(Σ지급 2,775,000+ΣMG 1,500,000=Σ로열티 4,275,000)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
