# 개인정보 마스킹·가명화

## 이 도구가 하는 일 (비개발자용)
운영 데이터를 개발·테스트·외부 공유용으로 넘길 때 개인정보를 마스킹·가명처리하는 도구입니다. 이 작업의 흔한 사고 두 가지 — 엉뚱한 컬럼에 숨은 개인정보를 놓치는 것, 그리고 "마스킹했다"는 믿음만 있고 증명이 없는 것 — 을 막는 데 초점을 맞췄습니다.

## 어떤 문제를 풀었나
"개발팀에 운영 데이터 좀 넘겨주세요"는 어느 조직에나 있는 요청이고, 어느 조직에서나 사고가 납니다. 사고의 패턴은 정해져 있습니다 — 이름·전화 컬럼은 지웠는데 '비고'란에 적어둔 전화번호가 남아 있고, 마스킹은 했는데 결과물을 아무도 다시 검사하지 않았고, 가명처리를 하고 나니 테이블끼리 조인이 깨져 받은 쪽에서 쓸 수가 없습니다. 셋 중 하나만 터져도 처리 전체가 무의미해집니다.

## 결과
- **개발·외부 공유용 데이터를 안전하게** — 운영 데이터를 넘기기 전에 전화·이메일·주민번호를 찾아 마스킹·가명처리합니다. "비고"란에 숨은 번호까지 값 패턴으로 잡습니다.
- **"지웠다"가 아니라 "증명했다"** — 처리 후 결과 전체를 다시 스캔해 잔존 0을 확인해야 완료로 칩니다. 같은 사람은 같은 가명이라 테이블 조인이 살아 있습니다.

## 쓰는 법
```
python data_mask.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (7/7 PASS)
- ① 심은 개인정보 전수 검출(이름6·전화 6+숨은1·이메일6·주민6·계좌6·주소6)
- ② ★처리 후 재스캔 잔존 0건(패턴+원본 이름)
- ③ 형식 보존(전화 010-****-nnnn · 이메일 도메인 유지)
- ④ ★일관 가명화(같은 사람=같은 가명 · 2파일 교차 일치=조인 보존)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
