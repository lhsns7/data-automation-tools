# 이메일 발송 자동화

## 이 도구가 하는 일 (비개발자용)
수신자 목록(CSV)과 템플릿으로 개인화된 알림 메일을 자동 발송하는 도구입니다. 주문 확인·정산 통지·리포트 배포처럼 회사가 자기 고객·파트너에게 보내는 거래·운영 알림 용도로 만들었습니다.

## 어떤 문제를 풀었나
주문 확인·정산 통지·주간 리포트 같은 알림 메일은 반복 업무의 전형입니다. 손으로 보내면 매일의 잔업이 되고, 자동화하면 이번엔 다른 공포가 생깁니다 — 같은 사람에게 두 번 나가거나, 개인화 값이 틀린 채로 나가는 사고입니다. 메일은 발송 취소가 없어서, 이 사고는 곧 사과 메일이 됩니다.

## 결과
- **한 명씩 보내던 안내 메일을 한 번에** — 수신자 목록(CSV)과 템플릿만 있으면 이름·금액이 들어간 개인화 메일과 첨부가 자동 발송됩니다 — 거래·정산·운영 안내 용도.
- **두 번 보내는 사고 없음** — 발송 대장이 성공자를 기억해 재실행해도 중복 발송이 0이고, 실패는 재시도·보류로 남아 누가 못 받았는지 바로 보입니다.

## 쓰는 법
```
python email_notify.py 수신자.csv --subject "제목 {이름}" --body-file 본문.txt
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 전수 수신 대조(수신자·개인화 제목·본문·첨부 SHA-256)
- ② 개인화 수기 대조(user05: 이름·주문번호·금액)
- ③ 일시 거부 → 재시도 성공(user07, 시도 2회)
- ④ 영구 거부 → 보류 격리(user23) + 나머지 29명 발송

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
