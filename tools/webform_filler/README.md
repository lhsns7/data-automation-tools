# 표

## 이 도구가 하는 일 (비개발자용)
CSV 목록을 웹 폼에 한 건씩 자동 입력·제출한다(브라우저 자동화, Playwright). 데스크톱 매크로의 웹 버전 — 접수·등록·신청 폼 반복 입력용.

## 쓰는 법
```
python webform_filler.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (2/5 PASS)
- ① 제출 수 정합
- ② 필드 단위 전수 대조(서버 기록 vs 원본)
- ③ 필수값 누락 격리(제출 금지)
- ④ 특수문자·긴 텍스트 보존

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
