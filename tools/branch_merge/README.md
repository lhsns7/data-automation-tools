# 지점·부서 엑셀 취합기

## 이 도구가 하는 일 (비개발자용)
본사·관리부서가 지점들에게 같은 양식의 엑셀/CSV를 받아 하나로 합치는 반복 업무를 자동화하는 도구입니다. 현실의 제출 파일은 양식대로 오지 않는다는 전제(컬럼명 변경, 순서 섞임, 제목 행, 합계 행, 이중 제출)에서 출발했습니다.

## 어떤 문제를 풀었나
"지점들이 보낸 엑셀 합치기"는 매달 반복되는 업무인데, 파일은 절대 양식대로 오지 않습니다. 누군가는 컬럼명을 자기 식으로 바꾸고, 누군가는 위에 보고서 제목을 얹고, 누군가는 표 중간에 합계 행을 넣고, 누군가는 어제 보낸 걸 고쳐서 또 보냅니다. 손 취합은 정확히 이 지점들에서 틀립니다.

## 결과
- **월말 취합을 폴더 하나로** — 지점들이 보낸 엑셀·CSV를 폴더에 넣으면 컬럼명이 달라도, 제목 행이 있어도 한 장으로 합쳐지고 지점별 요약까지 나옵니다.
- **이중 합산 사고 차단** — 같은 지점이 두 번 보내면 최신본만 채택하고 그 사실을 검수 리포트에 적습니다. 안 낸 지점은 명단으로 바로 보입니다.

## 쓰는 법
```
python branch_merge.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 취합 전수(5지점 행수·금액 = 심은 값)
- ② 양식 변형 흡수(컬럼명·순서 셔플·여분 컬럼 보고)
- ③ 상단 잡행 스킵 + 합계 행 제외(이중 계상 방지)
- ④ ★중복 제출 = 최신본만 채택(마커 확인·6행)·보고

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
