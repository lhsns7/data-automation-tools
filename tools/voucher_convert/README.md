# 주문/거래 내역 → 회계 전표

## 이 도구가 하는 일 (비개발자용)
판매 내역 CSV를 회계 시스템 업로드용 **전표(분개) 형식**으로 변환한다. 판매 1건 = 차변(결제수단별 채권 계정) / 대변(상품매출 공급가액 + 부가세예수금), 환불 = 역분개.

## 쓰는 법
```
python voucher_convert.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/7 PASS)
- ① ★차대 균형(전표별 차변합=대변합)
- ② 부가세 항등(공급+부가세=총액, 건별)
- ③ 수기 분개 대조(10,001원)
- ④ 면세(26건 부가세0)·환불(6건 역분개 균형)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
