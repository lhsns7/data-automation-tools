# 챗봇·RAG 품질 진단 도구

## 이 도구가 하는 일 (비개발자용)
이미 운영 중인 문서 Q&A·RAG 챗봇의 품질을 숫자로 진단하는 도구입니다. "챗봇을 만들긴 했는데 얼마나 정확한지 모르겠다"는 상황을 위해, 시스템 내부를 열지 않고(블랙박스) 응답만으로 어디가 약한지 축까지 짚어냅니다.

## 어떤 문제를 풀었나
챗봇·RAG를 도입한 팀의 공통 고민은 "품질을 어떻게 확인하냐"입니다. 데모에서 몇 번 잘 답하는 것과 실사용 품질은 다른 문제고, 특히 두 가지는 눈으로 잡기 어렵습니다 — 답을 냈는데 틀린 "오답"(모른다고 한 것보다 훨씬 위험합니다)과, 문서에 없는 내용을 그럴듯하게 지어내는 "환각"입니다.

## 결과
- **"우리 챗봇 괜찮나"를 숫자로** — 운영 중인 챗봇에 정답셋을 던져 정답률·근거 인용·거절 정확도·검색 적중을 점수로 냅니다 — 감이 아니라 리포트로 판단합니다.
- **고칠 곳을 축으로 지목** — 점수가 낮을 때 문서 부족인지, 환각인지, 검색층 문제인지를 구분해 처방을 씁니다 — 엉뚱한 곳을 고치는 비용을 줄입니다.

## 쓰는 법
```
python rag_audit.py --target http://챗봇주소 --evalset 평가셋.json
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (8/8 PASS)
- ① A 기준선 = rag_qa 자체 검증과 일치 + 처방 무결(오진 없음)
- ② B 실패 = 심은 5문항(삭제 문서) ∪ 기저 실패 + 비삭제 영역은 A와 동일
- ③ B 처방 = 커버리지 (기저 노이즈 섞여도 집중도 80%로 판별)
- ④ C: 범위밖 거절 0/4 검출 + 정상 질문 축은 A와 동일

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
