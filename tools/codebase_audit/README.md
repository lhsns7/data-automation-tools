# 레거시 코드 인수 진단 킷

## 이 도구가 하는 일 (비개발자용)
"기존 시스템을 유지보수·고도화해 달라"는 의뢰의 첫 주는 언제나 같은 일입니다 — 남이 만든 코드를 지도로 만드는 것. 어디에 무엇이 얼마나 있고, 어떤 라이브러리에 묶여 있고, 어디가 위험하고, 테스트가 있는지. 이 도구는 그 지도를 시간 단위로 뽑아 "1주차 코드 분석 산출"로 바로 제출할 수 있게 합니다. 언어 무관(PHP·Java·JS/TS·Python·C# 등), 오프라인 — 고객 코드는 밖으로 나가지 않습니다.

## 어떤 문제를 풀었나
유지보수·고도화 의뢰는 착수 전에 아무도 코드 안을 모릅니다. 발주자는 "그냥 기능 하나 추가"라고 생각하지만, 안에는 하드코딩된 비밀번호, 문자열로 이어 붙인 SQL, CP949와 UTF-8이 섞인 파일, 버전이 고정되지 않은 라이브러리, 그리고 테스트 0이 기다리고 있습니다. 이걸 모른 채 견적을 내면 개발자도 발주자도 다칩니다.

## 결과
- **낯선 코드를 첫 주에 지도로** — 소스 폴더 하나로 인벤토리·의존성·위험 좌표·구조 감각·리스크 점수·착수 순서가 리포트(md·엑셀)로 나옵니다 — 견적과 착수 판단의 근거가 하루 안에.
- **고칠 자리를 좌표로** — 하드코딩 비밀·SQL 결합·eval·인코딩 혼재·중복 파일을 파일:행으로 지목하고, 환경변수 비밀·바인딩 SQL·vendor는 제외해 "의심"만 남깁니다.

## 쓰는 법
```
python codebase_audit.py <소스폴더> --out <리포트폴더>
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (8/8 PASS)
- ① 인벤토리: PHP 파일 수 = 독립 계산(vendor 제외) · Java 2 · JS 2 · SQL 1 · 인코딩 utf-
- ② 의존성: 매니페스트 3종(composer·package·pom) 파싱 · 미고정 버전(^6.5·^4.17·${mysql.v
- ③ ★심은 위험 10종 전수 검출(파일:행 좌표 정확) · 초과 검출 0 · vendor 비밀은 제외
- ④ 클린 트리 오탐 0: 환경변수 비밀·파라미터 바인딩 SQL·테스트 존재 → 위험 0건

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
