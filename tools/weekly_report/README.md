# 판매 내역 → 주간 성과 리포트 자동화

## 이 도구가 하는 일 (비개발자용)
채널별 판매 CSV를 읽어 **주차별(월요일 시작, ISO 주차) 매출·건수, 전주 대비 증감, 채널 순위, 최근 주 상위 상품**을 서식 엑셀 리포트로 낸다. 수집기·API 출력에 그대로 붙는 리포트 층.

## 쓰는 법
```
python weekly_report.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (4/5 PASS)
- ① 독립 재집계 전수 대조(주차별 매출·건수·주 수)
- ② ★주차 경계 — 08-30(일)=08/24주 vs 08-31(월)=08/31주
- ③ 전주 대비 수기 대조(08/31주)
- ④ 격리(묵살 금지)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
