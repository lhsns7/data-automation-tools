# 오픈마켓 재고·가격 동기화

## 이 도구가 하는 일 (비개발자용)
기준 재고·가격표(CSV) 하나로 여러 오픈마켓의 재고와 가격을 자동으로 맞추는 도구입니다. 여러 마켓에 입점해 품절·가격을 화면마다 수작업으로 고치는 셀러·운영팀을 위한 쓰기 자동화입니다.

## 어떤 문제를 풀었나
여러 마켓에 입점한 셀러의 하루엔 품절 처리와 가격 변경이 마켓 수만큼 반복됩니다. 이걸 자동화하면 시간이 돌아오지만, 새로운 공포가 생깁니다 — 틀린 값이 실제 판매가가 되는 사고입니다. 0 하나 빠진 가격이 전 마켓에 뿌려지는 순간, 자동화는 사고를 확산시키는 장치가 됩니다.

## 결과
- **마켓마다 재고 고치는 일 소멸** — 기준표 하나만 고치면 바뀐 상품만 각 마켓에 전송되고, 전송 후 다시 읽어 실제 반영됐는지 확인합니다.
- **가격 오타 사고 차단** — 12,000원을 1,200원으로 잘못 적는 급변은 전송 전에 전 마켓에서 멈춥니다 — 손실이 나기 전에 사람을 부릅니다.

## 쓰는 법
```
python stock_sync.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① diff 전송(변경분만)
- ② ★read-back 전수 대조(반영=기준표, 서버 진실 일치)
- ③ 멱등(재실행 전송 0)
- ④ ★급변 가드(심은 오타 12,000대→1,200)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
