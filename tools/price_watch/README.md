# 경쟁가 추적·변동 알림

## 이 도구가 하는 일 (비개발자용)
경쟁 상품들의 가격을 주기적으로 수집해 이력을 쌓고, 의미 있는 변동만 골라 알리는 가격 감시 도구입니다. 특히 "우리 상품이 최저가 자리를 뺏겼는가/되찾았는가"라는 셀러의 실전 질문에 바로 답하도록 만들었습니다.

## 어떤 문제를 풀었나
가격 경쟁이 있는 셀러의 선택지는 둘 다 나쁩니다 — 경쟁가를 매일 눈으로 확인하거나(시간을 태움), 모든 변동에 울리는 알림을 달거나(며칠 만에 알림을 끄게 됨). 진짜 필요한 건 "의미 있는 변동만" 골라 울리는 감시입니다.

## 결과
- **경쟁가 확인을 사람이 안 함** — 경쟁 상품 가격을 주기적으로 모아 이력을 쌓고, 우리 상품이 최저가를 뺏기거나 되찾는 순간만 알립니다.
- **알림이 걸레가 되지 않음** — 설정 임계(기본 1%) 미만의 미세 변동은 울리지 않고 품절·복구는 상태로만 기록합니다 — 의미 있는 변동만 남습니다.

## 쓰는 법
```
python price_watch.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 파싱 전수 대조(3형식 12항목, 가격·재고)
- ② 첫 틱 알림 0(폭탄 방지 — Watcher 계약)
- ③ 심은 변동만 알림: 인하(-12%)·인상(+5%)·품절·뺏김×2 = 5건, ★0.47% 노이즈 0건
- ④ 같은 상태 재수집 = 알림 0(중복 0)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
