# 예약·접수 데스크

## 이 도구가 하는 일 (비개발자용)
상담·방문·점검 같은 신청을 받는 예약·접수 시스템입니다. 접수 폼(잔여 표시) → 검증 → 저장 → 관리자 즉시 알림 → 접수 대장 엑셀까지 한 몸으로 돌며, 시간대별 정원이 있어 마감되면 더 받지 않습니다.

## 어떤 문제를 풀었나
접수·예약은 "받는 것"보다 "제대로 거절하는 것"이 어렵습니다. 마감된 시간대에 동시에 들어온 신청 중 하나만 받아야 하고, 형식이 틀린 연락처는 저장 전에 걸러야 하고, 같은 사람의 이중 제출은 정중히 안내해야 합니다. 이걸 못 거르면 결국 운영자가 전화로 수습하게 됩니다.

## 결과
- **전화·카톡 접수를 폼으로** — 고객이 폼에서 시간대를 골라 접수하면 잔여 정원이 즉시 반영되고 담당자에게 알림이 갑니다 — 접수 누락과 이중 기록이 사라집니다.
- **초과 예약 구조적 차단** — 정원 2명 시간대에 5명이 동시에 눌러도 정확히 2명만 접수되고 나머지는 마감 안내를 받습니다 — 실제 동시 접속으로 검증했습니다.

## 쓰는 법
```
python booking_desk.py --serve
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 정상 접수 전수 대조(제출 의도 vs DB)
- ② 심은 불량 4종(이름 누락·유선번호·없는 슬롯·없는 항목)
- ③ ★동시 오버부킹(정원 2에 5건 동시)
- ④ 중복 재제출((연락처,슬롯) 유니크)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
