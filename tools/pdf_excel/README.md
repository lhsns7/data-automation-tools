# 거래명세서 PDF 묶음 → 정리 엑셀 추출기 (2026-09)

## 이 도구가 하는 일 (비개발자용)
폴더의 거래명세서/견적서 PDF들을 읽어 문서 정보(번호·일자·업체)와 품목 행(품명·수량·단가·금액)을 추출하고, 문서 요약 + 전체 품목 상세 + 검증 리포트를 서식 엑셀로 낸다.

## 쓰는 법
```
python pdf_excel.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (1/6 PASS)
- ① 문서 추출
- ② 왕복 전수 대조 — 문서 필드(일자·공급자·합계)
- ② 왕복 전수 대조 — 품목 행(품명·수량·단가·금액)
- ③ 합계 일관성(품목합 vs 인쇄합계)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
