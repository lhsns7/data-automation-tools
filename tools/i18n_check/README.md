# 번역 파일 정합 검사

## 이 도구가 하는 일 (비개발자용)
다국어 서비스의 번역 파일(JSON)이 조용히 어긋나는 것을 잡는 검사 도구입니다. 키가 빠지면 화면에 키 이름이 노출되고, 번역을 잊으면 기준 언어가 그대로 나가고, 플레이스홀더({name})가 어긋나면 문장이 깨지거나 앱이 죽습니다 — 전부 배포 전에 기계로 잡을 수 있는 사고입니다.

## 어떤 문제를 풀었나
번역 파일은 개발자·번역가·기획자가 같이 만지는 파일이라 어긋남이 기본값입니다. 개발자가 키를 추가하면 번역가의 파일에는 그 키가 없고, 번역가가 급해서 기준 언어를 복사해 두면 그게 그대로 배포되고, 번역 중에 {name} 하나가 빠지면 문장이 깨지거나 — 포맷 함수에 따라 — 앱이 그 화면에서 죽습니다. 그리고 이 모든 어긋남은 코드 리뷰에 안 걸리고 사용자 화면에서 발견됩니다.

## 결과
- **배포 전 번역 사고 차단** — 기준 언어와 대상 언어 파일을 대조해 빠진 키·번역 안 된 값·깨질 플레이스홀더를 키 이름까지 짚습니다 — 사용자 화면에서 발견되기 전에.
- **빌드에 한 줄** — 문제가 있으면 종료 코드 1을 돌려줘 CI 파이프라인에서 어긋난 번역이 배포되는 것 자체를 막습니다. 언어별 완성도 %도 함께.

## 쓰는 법
```
python i18n_check.py 기준.json 대상1.json [대상2.json …]
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 누락 키 3 정확(키 이름까지)
- ② 고아 키 2 정확
- ③ 미번역 4 정확 + 허용 목록(brand.name) 제외
- ④ ★플레이스홀더 불일치 2({name} 소실·여분 {cnt})

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
