# 오픈마켓 주문 수집·통합 허브

## 이 도구가 하는 일 (비개발자용)
여러 오픈마켓에 입점한 판매자의 주문을 API로 모아 하나의 표준 주문 대장으로 통합하는 도구입니다. 마켓마다 제각각인 응답 형식 때문에 주문 관리를 화면마다 오가며 수작업하는 셀러·운영팀을 위한 자동화입니다.

## 어떤 문제를 풀었나
여러 마켓에 입점하면 주문 확인만으로도 매일 화면 여러 개를 오가야 합니다. 그리고 통합을 시도하는 순간 진짜 문제가 드러납니다 — 마켓마다 API 응답의 필드명이 다르고, 날짜는 ISO·유닉스·한국식이 섞여 있고, 금액엔 콤마가 붙었다 말았다 하고, 페이징 방식도 상태 용어도 제각각입니다. 이 차이를 수작업으로 맞추다 보면 통합 자체가 새로운 오류의 원천이 됩니다.

## 결과
- **마켓별 로그인·다운로드 소멸** — 형식이 제각각인 마켓 API를 어댑터가 흡수해, 정해진 주기에 모든 마켓 주문이 한 장의 대장(엑셀)으로 모입니다.
- **신규·변경 주문만 보임** — 이전 수집과 비교해 새 주문과 상태가 바뀐 주문만 표시합니다 — 수백 건 대장에서 오늘 처리할 것을 찾지 않아도 됩니다.

## 쓰는 법
```
python order_hub.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 전수 필드 대조(71건 × 8필드)
- ② 정규화 수기 대조(ISO·유닉스·한국식 날짜 / 콤마 금액)
- ③ 페이징 소진(page 3장·offset·cursor)
- ④ 증분 수집(심은 신규 6·상태변화 5 — 기지 목록 대조)

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
