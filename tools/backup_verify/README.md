# 백업 자동화 + 복원 검증

## 이 도구가 하는 일 (비개발자용)
폴더를 주기 백업하면서, 백업 직후 실제로 복원해 해시 대장과 전수 대조하는 백업 도구입니다. 복원 검증을 통과하기 전에는 "백업 완료"라고 부르지 않습니다 — 복원 안 되는 백업은 디스크를 차지하는 희망사항일 뿐이라는 원칙으로 만들었습니다.

## 어떤 문제를 풀었나
백업 사고의 전형은 "잘 되고 있는 줄 알았다"입니다. 백업 스크립트는 매일 성공 로그를 남기는데, 정작 복원해야 하는 날 아카이브가 안 열리거나 절반이 비어 있는 경우 — 백업 성공 로그는 복원 가능성을 증명하지 않기 때문입니다.

## 결과
- **"복원되는 백업"만 백업으로 인정** — 백업마다 파일 해시 대장을 만들고 실제로 풀어 대조합니다 — 복원 안 되는 백업을 사고 당일에 발견하는 일이 없습니다.
- **이상 변경을 백업이 먼저 알림** — 파일이 한꺼번에 대량으로 바뀌면 경보가 뜹니다 — 랜섬웨어·오조작이 정상 백업을 덮어쓰기 전에 사람을 부릅니다.

## 쓰는 법
```
python backup_verify.py
```
데모 데이터가 동봉되어 있어 실행 즉시 결과와 검증 리포트가 생성됩니다. 실제 적용은 설정값(규칙·경로·계정)만 1회 맞춥니다.

## 검증 (6/6 PASS)
- ① 백업→★실제 복원 전수 대조(해시)
- ② 아카이브 1바이트 조작 → 재검(--check) 부패 검출
- ③ 심은 변경(수정3·추가1·삭제1) 정확 리포트
- ④ 무변경 재백업 = 변경 0

전체 항목은 같은 폴더의 검증 리포트(md)에 있습니다.

## 정직 고지
데모 화면·데이터는 합성 데이터입니다. 이 문서는 도구의 동작 범위를 설명하며, 회계·세무·법률 자문이 아닙니다.
